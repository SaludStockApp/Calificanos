PÁGINA DE CALIFICACIÓN

Incluye:
- Calificación por estrellas
- Comentario opcional
- Guardado en Supabase
- Pantalla separada de reseñas aprobadas
- Promedio general y total de opiniones
- favicon.ico

PUBLICAR EN GITHUB PAGES:
1. Crea un repositorio en GitHub.
2. Sube a la raíz:
   index.html
   style.css
   script.js
   logo.jpeg
   favicon.ico
3. Ve a Settings > Pages.
4. En Build and deployment elige Deploy from a branch.
5. Selecciona main y /(root).
6. Guarda.
7. GitHub te dará una URL pública.

Esa URL será la que se convierte en QR.

Supabase:
- Las reseñas se guardan en service_reviews.
- Solo los comentarios approved = true se muestran públicamente.

- Formulario centrado en pantalla.
